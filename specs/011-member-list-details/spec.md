# Member list details

## Requirements
- Closed rows show display name, avatar, membership/admin status and the saved account push setting.
- Use a bell for enabled push, a crossed bell for disabled push, and distinct loading or unknown states. Do not infer device permission or delivery from the setting.
- Keep full identity, contact fields, editing, invitations, push preferences/devices and explicit Remove member text inside keyboard-accessible details.
- Refresh the row icon when the push detail panel refreshes. Return focus after editing.
- Preserve search, Members/Not signed in/Removed tabs, removal safeguards, restoration and admin permissions.
- Support long names, missing contacts and mobile layouts.
