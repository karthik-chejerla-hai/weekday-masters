# Session lists and display settings

## Behavior

- The member Sessions page shows the next two upcoming sessions in the API's chronological order. This is a display limit, not a new RSVP eligibility rule.
- The dashboard shows the next game and one further game under "Future sessions". Admin session management retains the complete schedule.
- Session cards show the venue and configured court number on separate lines. The venue can wrap on small screens; the court label and number stay together. Do not confuse the physical court number with the number of courts used for capacity and settlement.
- Time and venue sit below the title, beside the date badge. RSVP status always sits beside the confirmed player count in the attendance panel.
- Admin Club Settings has a court number and a 12-hour / 24-hour time display choice. Blank court number means unassigned. Existing clubs retain 24-hour display until changed.
- The selected time format applies to session cards, the session details page and the admin schedule. Stored times and RSVP rules remain unchanged.
- Local review uses Court 8 and 12-hour time. Production is updated only after review and a later deployment request.

## Acceptance

Show only the first two of at least four upcoming games. Dashboard has one future card and no "Later sessions" heading. Save and reload settings. Check midnight, noon, unset court, mobile wrapping and unchanged admin schedule access.
